# Changelog

## 1.0.0 — 2026-10-18
First release.
- Side panel and full-tab notepad; notes saved as Markdown files in a user-chosen folder (File System Access API), browser-storage fallback with migration
- Autosave, crash-recovery draft, external-edit reload, conflict copies
- Write / Split / Read views, built-in Markdown renderer, clickable task lists
- Full-text search, pinned notes, Ctrl+K command palette, daily note
- Right-click clipping to Inbox.md, insert current page link
- Trash folder with Undo; themes, fonts, text size, ruled paper
